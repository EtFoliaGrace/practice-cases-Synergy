# Практические кейс-задачи (ознакомительная практика)

Три программы на Python, написанные в рамках ознакомительной практики.
## Задача 1
Шифрование Виженера
Файл: `vigenere.py`
## Задача 3
Дан одномерный массив A размерности N. Нужно найти сумму отрицательных элементов, которые расположены между максимальным и минимальным элементами.

Файл: `task3_sum_between_max_min.py`

## Задача 4
Известно суммарное число голов драконьей стаи N (0 < N < 100), у одного дракона не больше 7 голов. Сила стаи равна произведению числа голов у каждого дракона. Нужно найти максимально возможную силу. Решение: динамическое программирование.

Файл: `task4_dragons.py`

## Запуск
```
python vigenere.py
python task3_sum_between_max_min.py
python task4_dragons.py
```
